# 分页提示词契约

每一页是一条完整、独立的提示词，构图为 16:9 横版。页与页之间单独占一行，这一行只有：

```text
<!-- PAGE -->
```

不写解释，不用 Markdown 代码围栏。

每页按下面的顺序写八个字段。字段名使用中文冒号。

```text
页面类型：封面、目录、观点页、数据页、流程页、总结页之一；需要时用更具体的名称，例如痛点与价值页
标题：画面上的主标题
核心观点：希望观众记住的一句话
关键信息：最多 5 条，用分号隔开，全部来自材料原文
构图：主体位置、图表或场景关系、留白和视觉动线
色彩：这一套的主色、辅助色和强调色
可见文字：真正需要出现在画面上的文字，用分号隔开
避免项：不要出现的元素、错误信息和无关装饰
```

合格密度见 `assets/example-deck.txt`。
