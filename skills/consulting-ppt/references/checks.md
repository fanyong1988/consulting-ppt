# 画面检查

逐页看图。失败时，把对应补充句追加到该页提示词的末尾，只重做这一页。

| 现象 | 补充句 |
| --- | --- |
| 中文太小或乱码 | 可见文字不超过 20 个汉字，使用清晰大号无衬线中文字体 |
| 页面信息太满 | 只保留 3 个信息层级，四周留白充足，不放长段正文 |
| 页面之间风格不一致 | 沿用整套的配色、字体气质、图标线条和边距系统 |
| 画面里出现材料没有的数据 | 只使用材料中逐字出现的数据；没有数据时不得补写百分比 |
| 画面像海报而不像演示页 | 16:9 商务演示页面，使用网格和信息层级，避免宣传海报式装饰 |
| 出现无关 Logo 或未提供的机构名 | 不要生成任何 Logo、品牌水印或未提供的机构名称 |
