# 咨询报告演示页

把用户给出的材料做成一套 16:9 整页图片。每一页是一张画面。出图只用 Codex 内置的 `image_gen`，不需要 API Key，也不向用户索取。

写提示词前读 `references/prompt-contract.md`。确定视觉前读 `references/visual-system.md`。接受画面前读 `references/checks.md`。拿不准一页该有多满时读 `assets/example-deck.txt`。

## 步骤

### 1. 补齐事实

同时确认五件事：材料、受众、页数、视觉风格、必须保留的事实。页数可以是「由内容决定」。用户没指定视觉风格时用咨询报告。必须保留的事实可以是「没有」。

缺任何一项时，用中文追问，一次最多两个问题。这一轮只提问，不写整套提示词，也不出图。

### 2. 分页

按内容逻辑分页。用户指定了页数，就用该页数。一页一个核心观点。关键信息的条数上限以 `references/prompt-contract.md` 为准，每一条都能在材料里找到原文。条数放不下时拆成下一页；用户锁定了页数、又放不下时，先问留下哪几条。

### 3. 写提示词

按 `references/prompt-contract.md` 写出每一页，并用其中规定的分页行隔开。把全部页面写入 `prompts.txt`。这个文件里只有提示词。

### 4. 加上风格前缀

从 `references/visual-system.md` 取出选定风格的前缀。整套只用一种风格。送去生图的文本是风格前缀、一个空行、该页八个字段。该页已经以同一前缀开头时，不再加第二遍。

### 5. 逐页出图

`prompts.txt` 写完后，立刻用内置 `image_gen` 逐页出图。每页调用一次，一次一张。送入的文本是第 4 步拼好的提示词，并在其中写明 16:9 横版。分页行、写作说明和推理不进入画面。

用户给了参考图时，先用 `view_image` 让该图进入当前上下文，再让 `image_gen` 按这张参考图生成，并在提示词里写明要保持的特征。

生成后，把画面复制到交付目录，按页码命名。内置工具默认写在 `$CODEX_HOME/generated_images/` 时，从那里复制出来。不要改走 `scripts/image_gen.py` 或任何需要 API Key 的接口。某一页生成失败时，说明这一页没有生成，继续完成其余页。

### 6. 检查

用 `references/checks.md` 检查每一张图。只重做失败的那一页：把表中对应的补充句写入该页后，仍用 `image_gen` 再生成这一页。补充句不能带来材料里没有的事实。

### 7. 交付

放在一个目录里：

```
<名称>/
  prompts.txt
  01-<短标题>.png
  02-<短标题>.png
```

告诉用户这些是整页画面，画面上的文字不能再当文本框修改。

## 硬性约束

- 不编造材料里没有的数据、人物、Logo、机构名称或结论。
- 画面上只出现标题、数字和短标签。可见中文过长时，压到标题和不超过约 20 个汉字的短标签。
- 材料里没有数字时，用关系图或流程图，不画百分比或带刻度的图表。
- 整套页面共用一套主色、辅助色、强调色、字体气质和边距。
- 写作说明、推理和分页行不出现在画面上。
